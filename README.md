# [2D Troll Game]

A game built in **Unity** during my Erasmus internship at **Arcan Studios**.

It's a simple game, troll themed, in which you have to kill all the enemies in order to proceed to the next level, the game has only one working level so eventually in the future i will add more.

## About the Project

The project was developed over roughly **50 hours**. Since we were a group of beginners in an Erasmus mobility, a large part of the time went into learning: everyone had to understand how Unity works, which made the process slower, but also a great learning experience.

- **Art:** all models were drawn as vector graphics in **Inkscape**.
- **Game logic:** instead of writing traditional code, we used Unity's visual approach, building the game's behavior by connecting and configuring components in the editor.
- **Engine:** Unity.

## Download and Run

1. Go to the [**Releases**](../../releases) section of this repository.
2. Download the `.zip` archive from the latest version.
3. Extract it into a folder.
4. Run `game.exe`.

**Requirements:** Windows (64-bit build).

## Controls

Basic controls [WASD - Movement, Space - Jump, Click - Shoot]

## What I Learned

- Working in a team on a game project, from the initial idea to the final build.
- The basics of the Unity engine: scenes, objects, components, and visual logic.
- Creating vector assets in Inkscape and using them in a game.
